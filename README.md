
# Controle de Níveis de Água

## Descrição
Sistema de monitoramento simulado de um reservatório de água,
desenvolvido em Python.

## Funcionalidades
- Armazena cinco níveis de água em uma lista.
- Exibe mensagens coloridas com a biblioteca Colorama.
- Utiliza uma função para definir as cores.
- Mostra a situação atual do reservatório.

## Tecnologias
- Python
- Colorama

## Instalação
Execute no terminal:

python -m pip install colorama

## Execução
Execute:

python app.py
